# Mall Exploratory Data Analysis (EDA)

This repository contains an exploratory data analysis of mall movement and activity data using big data technologies.

## Overview

The analysis focuses on understanding user behavior in a mall setting, including movement patterns, dwell times, Wi-Fi access point coverage, and user-level summaries. The project demonstrates proficiency in big data processing and visualization.

## Technologies Used

- **PySpark**: For handling large datasets and distributed computing.
- **Pandas**: For data manipulation and analysis.
- **Matplotlib & Seaborn**: For creating insightful visualizations.
- **Jupyter Notebook**: For interactive analysis and documentation.

## Key Achievements

### Big Data Processing
- Utilized PySpark to process merged datasets containing movement logs, user data, and Wi-Fi signals.
- Handled timestamp conversions and aggregations on large-scale data.
- Demonstrated ability to work with distributed dataframes in a big data environment.

### Data Visualization
- Created multiple types of plots: heatmaps, scatter plots, bar charts, line charts.
- Implemented conditional visualizations based on data availability.
- Organized outputs into structured folders with images and documentation.

### Folder Structure
- `EDA_Outputs/`: Contains generated visualizations and READMEs for each analysis section.
  - `Combined_Movement_Heatmap/`: Movement visualization with event categories.
  - `User_Level_Summary/`: User-based summaries (sessions, images, events, floors).
  - `Floor_wise_Dwell_Time/`: Time spent per floor.
  - `Movement_Density_Map/`: Density heatmap of movement.
  - `WAP_Coverage_Map/`: Wi-Fi signal strength visualization.

## How to Run

1. Ensure you have PySpark, Pandas, Matplotlib, and Seaborn installed.
2. Load the notebook in Jupyter.
3. Execute the cells to generate visualizations and folders.
4. Each plotting cell creates a folder with the plot image and a README explaining the visualization.

## Insights

- Identified high-traffic areas in the mall.
- Analyzed user engagement through sessions and events.
- Mapped Wi-Fi coverage for network optimization.
- Calculated dwell times to understand floor popularity.
